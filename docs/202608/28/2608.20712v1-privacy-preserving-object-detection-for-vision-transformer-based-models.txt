Abstract —We propose a novel object detection method that enables us to protect sensitive visual information of test images. Previous studies considering visual information protection focus on image classification tasks. This paper proposes an object detection method using perceptual encryption for the first time. The proposed method can achieve almost the same accuracy as that of models without any protection by utilizing the embedding structure of the Vision Transformer (ViT) and a domain adap-tation technique with keys. In experiments, the effectiveness of the proposed method is verified in terms of accuracy and visual protection under the use of ViTdet, which is a ViT-based object detection model. 

Index Terms —Object Detection, Vision Transformer, Image Encryption, Privacy Preserving 

I. I NTRODUCTION 

The vision transformer (ViT) [1] trained with perceptual encryption has achieved great success in various applications such as privacy-preserving learning [2]–[4], access control, model protection [5], and adversarial defense [6], [7]. How-ever, previous studies focus on image classification tasks [8]. Accordingly, in this paper, we propose a novel object detection method using perceptional encryption for the first time. In the proposed method, the ViTdet [9] model, which employs the ViT, is used as a base model for object detection. Perceptional encryption and a domain adaptation technique with secret keys studied for image classification are expanded for object detection. In experiments, the proposed method is demonstrated to be effective in object detection in terms of detection accuracy and visual protection. II. R ELATED WORK

A. Setup 

In experiments, an object detection task was performed by using the COCO dataset [11] as test images, which consists of 80 object categories. The performance of trained models was also evaluated with the “val2017” subset as validation images from the COCO dataset. Furthermore, we extended our evaluation to the LVIS dataset [12]. While LVIS shares the exact same images as those of the COCO dataset, it is characterized by different data splits and significantly richer annotations. Unlike the 80 categories in COCO, LVIS features a massive vocabulary of 1,203 categories. To comprehensively assess detection performance, we adopted ViTdet as a vision transformer-based model with the Mask R-CNN framework. For evaluation metrics, we employed the standard Average Precision (AP) scores, which range from 0 to 100, where a higher value indicates superior performance. To evaluate performance across different object scales, we utilized AP s,AP m, and AP l for small (area < 32 × 32 ), medium ( 32 × 32 ≤

area ≤ 96 × 96 ), and large (area > 96 × 96 ) objects. 

B. Experimental Results 

Table I presents the evaluation results of object detection accuracy (AP) under various conditions. In this evaluation, ViTdet models with three different backbones (ViT-B, ViT-L, and ViT-H) were utilized. These models correspond to the three models called “model final 61ccd1.pkl”, “model final 6146ed.pkl”, and “model final 7224f1.pkl” published on the official ViTdet GitHub repository. “Baseline” represents the results obtained using both non-encrypted models and images. “Without model encryption” shows results when only the images were encrypted and the models were not encrypted. In the table, “Proposed” denotes the proposed method utilizing both encrypted model and images. As shown in Table I, it was confirmed that the proposed method achieved almost the same as that of the non-encrypted models. Theoretically, the proposed block-wise encryption can cancel out the influence of the image encryption at the embedding layer, but the accuracy was slightly different from that of “Baseline” due to the influence of JPEG compression used in the COCO dataset. V. C ONCLUSION 

We proposed a privacy-preserving method for object detec-tion that utilizes the embedding structure of Vision Transform-ers (ViTs). Using a ViTdet as a representative example, we demonstrated that applying block-wise encryption effectively protects visual information while maintaining high detection accuracy equivalent to that of non-encrypted models. Fur-thermore, the significant decrease in accuracy observed when only the images were encrypted demonstrates the necessity of encrypting the model’s embedding layer.
